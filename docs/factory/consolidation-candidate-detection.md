# Consolidation Candidate Detection

MOD-03 adds deterministic `CONSOLIDATE` hypotheses to the WLD-11 modernization disposition contract.

A consolidation candidate is **not** a merge instruction and does not establish functional equivalence. The current foundation uses canonical structural affinity such as shared datasets, shared downstream consumers, and shared external dependencies to identify workload boundaries worth comparing. Shared infrastructure alone remains low-confidence evidence.

Every candidate retains its peer boundary, supporting signal identifiers, blockers, confidence, and the explicit fact that behavior equivalence has not been established. Selection remains unresolved and governed confirmation is always required.

MOD-08 is expected to add transformation/business-rule similarity evidence. That later evidence can strengthen or reject these structural hypotheses without replacing the canonical disposition model.
