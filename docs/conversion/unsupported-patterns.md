# Unsupported Patterns

Unsupported behavior is a normal factory state.

## Requirements

When an unsupported pattern is encountered, the factory should:

1. identify the source location
2. record the construct
3. preserve it in provenance
4. estimate impact
5. select AI-assisted or human-supervised routing
6. avoid silently generating an approximation

## Pattern Registry

Unsupported patterns should be aggregated across workloads. Repeated patterns become candidates for deterministic rule development.
